# Contributing

Thanks for helping. To add an entry, open a pull request that:

1. Adds one item to the right section, in alphabetical order.
2. Uses the format `- [Name](link) - Short description ending with a period.`
3. Points to something that works today: a live service, or a repository that is not archived and has had activity in the last 12 months.
4. Describes the tool plainly, without marketing claims.

We don't list:

- temporary or disposable email services, or tools for creating accounts in bulk;
- tools for cold outreach, bulk or marketing email.

Entries that stop working or get archived are removed.
